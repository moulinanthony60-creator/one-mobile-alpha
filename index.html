☁️ Profil ONE chiffré · Alpha 0.11
Ton profil et le coffre plateformes sont chiffrés dans le navigateur avant envoi au cloud. La clé de déchiffrement est dérivée de ton mot de passe ONE. Les états YouTube/Twitch/TikTok peuvent ainsi être restaurés sur un autre appareil. Un jeton expiré peut toutefois nécessiter une nouvelle autorisation auprès de la plateforme.

La synchronisation automatique protège les préférences ONE sans copier les clés API ni les tokens OAuth.
