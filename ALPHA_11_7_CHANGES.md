# ONE Mobile Alpha 0.11.7 — TikTok Share

- Base conservée depuis la 0.11.6 qui s’installe correctement via Chrome/Google Play.
- Réactivation du Web Share Target Android.
- ONE accepte les partages texte/lien via `share_target`.
- Un lien TikTok reçu ouvre ONE, préremplit l’import TikTok et attend la validation « Ajouter ».
- Cache Service Worker incrémenté pour forcer la mise à jour.

Après déploiement, mettre à jour/réinstaller ONE afin qu’Android enregistre la nouvelle cible de partage.
