# ONE Mobile Alpha 0.11.4 — Chrome Install Fix

- Manifeste simplifié et conservateur pour Chrome Android.
- Nouveau `manifest.json` lié directement depuis `index.html`.
- `id`, `scope`, `start_url` et icônes utilisent des URLs relatives cohérentes avec GitHub Pages.
- Icônes déclarées avec `purpose: any` pour éviter qu’une icône non conçue comme maskable invalide la présentation.
- Service worker simplifié et cache versionné `0.11.4`.
- Share Target conservé en GET, une fois l’installation Chrome validée.
- Branding mis à jour en Alpha 0.11.4.
