# ONE Alpha 0.11 — Partage Android

## Installation
Remplacer les fichiers à la racine du dépôt GitHub Pages par le contenu de ce dossier. Ouvrir ONE depuis Chrome sur Android et installer l’application si nécessaire. Chrome doit ensuite prendre en compte le nouveau manifeste pour faire apparaître ONE dans le menu de partage ; la mise à jour peut ne pas être immédiate.

## Utilisation
TikTok > Partager > Plus (si nécessaire) > ONE. ONE ouvre le champ prérempli : appuyer sur Ajouter. Les imports multiples et le catalogue 0.10 sont conservés.

## Limites
Cette fonction reçoit des liens, pas des fichiers vidéo. Les liens courts TikTok restent dépendants d’oEmbed et peuvent nécessiter une adresse complète. Elle ne récupère pas automatiquement les vidéos d’un créateur ou le flux TikTok. L’apparition dans le menu Android doit être testée sur le téléphone avec ONE installée.
