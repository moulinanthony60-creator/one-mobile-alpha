# ONE Mobile Alpha 0.10 — Import TikTok multiple

- Collez plusieurs liens ou un texte de partage dans Réglages > TikTok.
- Jusqu’à 20 liens par import, doublons ignorés, bilan affiché.
- Les liens en échec restent disponibles pour réessayer.
- Le catalogue reste limité à 120 vidéos sans supprimer automatiquement les anciennes.
- Validation des domaines TikTok et délai réseau limité à 8 secondes par lien.
- Catalogue et synchronisation 0.9 conservés.
- Liens courts : résolution tentée via oEmbed, non garantie selon TikTok/CORS. Aucun suivi automatique des créateurs ni récupération du flux Pour toi TikTok.

## Installation
Remplacer les fichiers du dépôt GitHub Pages avec le contenu de ce dossier. Le cache PWA est versionné 0.10.
