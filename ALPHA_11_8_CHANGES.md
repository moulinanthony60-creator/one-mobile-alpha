# ONE Mobile Alpha 0.11.8 — TikTok Auto-Import

- Conserve le `share_target` Android validé en 0.11.7.
- Quand une vidéo TikTok est partagée vers ONE, le lien reçu est importé automatiquement.
- Plus besoin d’appuyer manuellement sur **Ajouter** après le partage.
- Le catalogue TikTok externe, le feed et la synchronisation ONE restent inchangés.
- Les liens invalides ou non résolus restent affichés pour permettre une correction manuelle.
