# ONE Mobile Alpha 0.6

- Compte ONE avec création de compte, connexion et déconnexion.
- Sessions via ONE Account & Profile Cloud 0.6.
- Profil cloud lié au compte ONE et non plus seulement à un ID local.
- Chiffrement AES-GCM côté navigateur ; clé de profil dérivée du mot de passe et de l’ID ONE pour permettre la restauration multi-appareils.
- Modification du nom ONE synchronisée avec le backend.
- Compatibilité conservée avec les connexions YouTube, Twitch et TikTok locales.
- Les secrets/API OAuth ne sont pas inclus dans la sauvegarde cloud.
